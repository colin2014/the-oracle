===== A1.1.1  (src=sidebar, kept=13, dropped=0) =====
  KEEP  Central Processing Unit (CPU): The part of a computer that executes program instructions and coordinates the activity of other components; it processes data and controls information flow.
  KEEP  Control Unit (CU): The CPU subcomponent that fetches and decodes instructions and sends control signals so the ALU, registers, memory and I/O act in the correct sequence.
  KEEP  Arithmetic Logic Unit (ALU): The portion of the CPU that performs arithmetic (e.g., add, subtract) and logical (e.g., compare) operations on data supplied by registers.
  KEEP  Register: A very small, very fast storage location inside the CPU used to hold instructions, addresses, operands or intermediate results while they are processed.
  KEEP  Program Counter (PC): A register that holds the address of the next instruction to be fetched from memory.
  KEEP  Instruction Register (IR): A register that holds the instruction currently being decoded and executed.
  KEEP  Memory Address Register (MAR): A register that holds the memory address the CPU will read from or write to.
  KEEP  Memory Data Register (MDR): A register that temporarily holds data being transferred between CPU and memory.
  KEEP  Accumulator (ACC): A register commonly used to store intermediate results produced by the ALU.
  KEEP  Cache: A small amount of very fast memory near the CPU that stores frequently used instructions and data so the CPU can access them more quickly than from RAM.
  KEEP  Clock speed (Clock rate): The frequency of the CPU’s internal clock, measured in hertz; it sets how many basic cycles the CPU can perform per second.
  KEEP  Clock cycle: One tick of the CPU clock when part of an instruction can be processed; many instructions require multiple cycles.
  KEEP  Bus: The set of signal lines used to transfer data, addresses and control signals between the CPU, memory and peripherals.

===== A1.1.4  (src=sidebar, kept=9, dropped=0) =====
  KEEP  Primary memory (main memory): The fast, CPU-accessible storage used to hold program instructions and data while a program runs; it consists mainly of RAM and ROM.
  KEEP  RAM (Random Access Memory): Read/write, volatile memory used to store currently running programs and their data; contents are lost when power is removed.
  KEEP  ROM (Read-Only Memory): Non-volatile memory used to store permanent firmware (e.g., boot code); it cannot normally be overwritten during regular operation.
  KEEP  Volatile: A property of memory that requires continuous power to retain data (e.g., RAM).
  KEEP  Non-volatile: A property of memory that preserves data when power is removed (e.g., ROM, secondary storage).
  KEEP  DRAM (Dynamic RAM): The common form of main RAM; needs frequent refresh cycles and is relatively cheap per bit.
  KEEP  SRAM (Static RAM): Faster and more expensive than DRAM; typically used for small, very fast cache memory.
  KEEP  Cache memory (L1, L2, L3): Very small, very fast SRAM placed close to the CPU to store the most-used instructions/data and speed up access.
  KEEP  Virtual memory: A technique that uses secondary (disk) storage to extend the effective size of RAM by swapping pages between RAM and disk.

===== A1.1.6  (src=sidebar, kept=10, dropped=0) =====
  KEEP  Pipelining: A CPU design technique where multiple instructions are overlapped in execution by dividing the instruction cycle into several stages (fetch, decode, execute, memory, and write-back). This increases overall instruction throughput.
  KEEP  Instruction Throughput: The number of instructions a CPU can complete per unit of time. Pipelining improves throughput without increasing the clock speed.
  KEEP  Pipeline Stall: A pause in the instruction pipeline that occurs when an instruction depends on the result of a previous one that has not yet completed.
  KEEP  Hazard: A situation in which a pipeline must delay or alter the normal sequence of instruction execution. Common types include data hazards, control hazards, and structural hazards.
  KEEP  Clock Cycle: The smallest unit of time during which the CPU performs one operation or part of an instruction. Pipelining enables one instruction to complete every clock cycle under ideal conditions.
  KEEP  Multi-core Processor: A single CPU that contains two or more independent processing cores, each capable of running its own sequence of instructions simultaneously.
  KEEP  Parallel Processing: The simultaneous execution of multiple instructions or tasks across multiple CPU cores to increase performance and efficiency.
  KEEP  Cache Memory: A small, high-speed memory located inside or close to the CPU that stores frequently accessed data and instructions, reducing the time needed to fetch them.
  KEEP  Thread: A sequence of instructions that can be managed independently by a CPU core; multiple threads can run in parallel on a multi-core processor.
  KEEP  Scalability: The ability of a computer system or CPU architecture to increase performance efficiently as more resources (like additional cores) are added.

===== B4.1.6  (src=sidebar, kept=5, dropped=0) =====
  KEEP  Abstract Data Type (ADT): A model for data structures that specifies behavior, not implementation.
  KEEP  Abstraction: Hiding unnecessary details and focusing on essential features.
  KEEP  Encapsulation: Combining data and operations into a single unit with restricted access.
  KEEP  Interface: The set of operations available to users of an ADT.
  KEEP  Implementation: The internal mechanics that realize the operations of an ADT.
