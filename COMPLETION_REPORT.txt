                           USAGE INSTRUCTIONS
================================================================================

1. START THE APP:
   python app.py
   # Access at http://localhost:5000/dashboard

2. FIRST-TIME USER:
   - Onboarding tour automatically starts
   - Follow 4-step guided tour
   - Can skip with button or Esc key

3. NAVIGATE DASHBOARD:
   - Use nav links at top (active state shows)
   - Use global search with Ctrl+K
   - Sort/filter assignments with dropdowns
   - See progress bar and time estimates

4. KEYBOARD SHORTCUTS:
   - Ctrl+K: Open global search
   - Escape: Close modals/tour
   - Tab: Navigate elements
   - Arrow keys: Menu navigation

5. MOBILE USAGE:
   - Responsive design auto-adapts
   - Touch-friendly buttons
   - Navigation stacks vertically
   - All features work on mobile
